🔐 AccessFlow

Backend SaaS para Autenticação, Autorização e Auditoria
Desenvolvido por Kevin Prieto

O que é AccessFlow?

01
Autenticação Completa

Sistema backend robusto para gestão completa de autenticação de usuários

02
RBAC

Controle de acesso baseado em roles (Role-Based Access Control)

03
Auditoria

Sistema de auditoria automática de todas as ações

04
Multi-tenant

Suporte completo para múltiplas organizações

05
API REST

API RESTful completa e documentada

Clean Architecture

🎯 Domain Layer
Entidades puras: User, Organization, Role, Permission
💼 Application Layer
DTOs e Serviços de negócio
🔧 Infrastructure Layer
PostgreSQL, JPA, Security
🌐 API Layer
Controllers REST
